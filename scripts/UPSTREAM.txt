Provenance of the copied scripts
================================

xyzToCube.py, constants.py and ansi.py are byte-identical copies taken from the
PyMOL pipeline:

    repository : https://github.com/FlxLfr/esp_visualization
    branch     : main
    commit     : ed3b0d0  (2026-08-25, "Finalization, creating a test script
                 for parameter evaluation")
    taken on   : 2026-08-25

They were copied verbatim so that `diff` against the upstream file stays clean
and any divergence is visible at a glance.

Why a copy and not a submodule
------------------------------
The grid conversion is viewer-independent: a Gaussian cube is a Gaussian cube.
Copying keeps this repository self-contained - it clones and runs without the
PyMOL repository being present, which matters because the two are meant to be
compared side by side by someone who may only have been given one of them.

The cost is drift. The rule that keeps it manageable:

  * Do not edit these three files here. Fix them upstream, then re-copy and
    update the commit hash above.
  * The one exception is the `esp.pml` writer inside xyzToCube.py, which has no
    meaning for VMD. It gets replaced by a `esp.tcl` writer - and once that
    happens, the file is a genuine fork and this note must say so.

To check whether the copies are still current:

    diff scripts/xyzToCube.py ../Pymol_esp_visualization/scripts/xyzToCube.py
